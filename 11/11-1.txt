배틀그라운드에서 3판 동안 기록한 킬 수를 배열에 저장했다. 다음 코드의 실행 결과는?

int kill[3] = {3, 7, 5};
printf("%d", kill[1]);

① 3

② 7

③ 5

④ 오류 발생

정답: 2번

char champion[] = "Ahri";

② 4

④ 6

3번. 배틀그라운드 플레이어 정보

다음 구조체에서 플레이어의 체력을 출력하는 올바른 코드는?

struct Player {
    int kill;
    int hp;
};

struct Player p = {5, 80};

① printf("%d", p.kill);

② printf("%d", p[hp]);

③ printf("%d", Player.hp);

④ printf("%d", p.hp);

정답: 4번

4번. 롤 챔피언 공격력

롤 챔피언 3명의 공격력을 배열에 저장했다. 다음 코드의 실행 결과는?

int damage[3] = {100, 200, 300};
int total = 0;

for (int i = 0; i < 3; i++) {
    total += damage[i];
}

printf("%d", total);


① 300

② 500

③ 600

④ 900

정답: 4번

5번. 배틀그라운드 스쿼드

배틀그라운드 스쿼드의 플레이어 정보를 구조체 배열에 저장했다. 다음 코드의 실행 결과는?

struct Player {
    int kill;
};

struct Player team[3] = {
    {3}, {5}, {7}
};

team[1].kill += team[0].kill;

printf("%d", team[1].kill);

① 3

② 5

③ 8

④ 15

정답: 3번
