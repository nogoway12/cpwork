난수 생성이랑 시드 설정하기: <stdlib.h>랑 <time.h> 불러와서 srand(time(NULL))로 매번 다른 난수 패턴이 나오게 초기화하고, rand() 써서 게임 같은 데 쓰기 좋은 무작위 숫자를 만들어봤음무한 루프랑 조건문으로 흐름 제어하기: while(1) 써서 프로그램 계속 돌아가게 만들고, 사용자가 입력한 값에 따라 if-else로 분기 타면서 특정 조건 맞으면 break로 빠져나오는 제어 흐름을 짜봄가변 매개변수 써보기: <stdarg.h>에 있는 va_list, va_start, va_arg, va_end 매크로 이용해서, 들어오는 인자 개수 상관없이 유연하게 쓸 수 있는 함수(예: 숫자 여러 개 다 더해주는 sum() 함수 같은 거)를 직접 구현해 보았다
