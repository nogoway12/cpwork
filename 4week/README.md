# 4주차 학습 내용 요약

이번 주차에 작성한 예제 코드(`ex7-10.c`, `guess_number.c`, `var_args_sum.c`)들을 통해 다음과 같은 C언어의 핵심 개념들을 학습할 수 있었습니다.

1. **난수 생성 및 시드(Seed) 초기화**: `<stdlib.h>`와 `<time.h>` 라이브러리를 활용하여 `srand(time(NULL))`로 매번 다른 난수 패턴을 만들고, `rand()` 함수를 통해 게임 등에 필요한 무작위 숫자를 생성하는 방법을 익혔습니다.
2. **무한 루프와 조건문 제어**: `while(1)`을 활용해 프로그램이 지속적으로 실행되게 만들고, 사용자의 입력값에 따라 `if-else`문으로 논리를 분기하며, 특정 조건 달성 시 `break`로 루프를 탈출하는 제어 흐름을 구현했습니다.
3. **가변 매개변수(Variadic arguments) 활용**: `<stdarg.h>` 헤더 파일이 제공하는 `va_list`, `va_start`, `va_arg`, `va_end` 매크로를 이용해, 넘어오는 인자의 개수가 정해져 있지 않은 유연한 함수(예: 임의의 여러 숫자를 더하는 `sum()` 함수)를 직접 구현해 보았습니다.
